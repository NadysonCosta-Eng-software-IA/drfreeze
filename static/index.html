Configurar Wi-Fi via QR Code

📋 Como funciona:

  1. Ligue o ESP32 novo na tomada
  2. Ele criará uma rede Wi-Fi chamada "DrFreeze_Config"
  3. Conecte seu celular nessa rede
  4. Uma página abrirá automaticamente para configuração
  5. Ou escaneie o QR Code gerado no cadastro
